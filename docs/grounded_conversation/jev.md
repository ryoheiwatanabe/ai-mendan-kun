# JEVを使う本体の回答処理

2026年9月18日にJEVの採用を決定し、既存のテキスト・音声APIへ接続した。本人用の保護されたプレビューで有効にし、公開中サイトの切替とmainへのマージは本人試用後に行う。

## 通常の処理

既存のルーティング・公開根拠検索 → `{text, answerability, evidenceIds}` の候補生成 → 形式・根拠ID・文字数・名前の確認 → JEV → 公開状態の再確認 → 表示・読み上げ。

JEVは旧LLM校閲を置き換える。通常は生成1回とJEV1回、形式や意味の修復が必要なときだけ最大1回追加する。生成・JEVとも1問2回まで。修復後も点検し、不合格の本文は表示・音声化しない。旧校閲への自動切替や、生成後の追加検索は行わない。

Factとチャンクを共に渡し、送信前・JEV直前・最終送出前に公開・承認・所有者・現行版・本文を再確認する。音声の生成・配信中も既存の再確認を維持する。会話履歴は今回のリクエストの直近2往復までで、合計3,600字を超える場合は直近1往復に絞る。履歴を事実の根拠にはしない。定型の挨拶・拒否、対象確認、根拠がない案内、有効な経歴概要キャッシュには生成やJEVを追加しない。

JEVの通信・応答形式の失敗は `JEV_UNAVAILABLE`、点検不合格は `ANSWER_REJECTED`、生成等の失敗は `ANSWER_PROCESSING_FAILED`。本人の情報不足と区別し、入力へ復帰する。中止は生成・JEV・音声へ伝える。JEVが確認した本文を変更せず表示・読み上げる。

## 設定と切り戻し

| 設定 | 値・用途 |
| --- | --- |
| `ANSWER_PIPELINE` | `jev_v1` で有効、`legacy` で旧経路。未指定はlegacy。 |
| `TYPESAFE_API_KEY` | Workers Secret。値を設定ファイルやブラウザへ渡さない。 |
| `JEV_TIMEOUT_MS` | 1回のJEV通信はデフォルト4,000ms。 |
| `ANSWER_TIMEOUT_MS` | 検証済み本文を返すまでデフォルト25,000ms。読み上げ待ちは別。 |
| `JEV_THRESHOLDS_JSON` | 下記6軸の閾値を必要な軸だけ上書きするJSON。 |

生成は既存のOpenCode Go / OpenAI互換Providerを使用する。今回の試用設定は既存の `glm-5.3-flash`、検索は既存のWorkers AI、STT/TTSは既存のGemini。JEV送信先は `https://api.typesafe.ai/v1/systemone` に固定し、リダイレクトしない。送信先は質問前の既存画面にも表示する。

初期閾値は、対象一致0.80、項目一致0.65、根拠支持0.80、因果の非創作0.80、範囲保持0.80、不要な棄権の回避0.60。各軸を独立して判定する。因果や主体の不合格を他の高得点で相殺しない。暫定の採否基準であり、校正された正答確率ではない。

試用版には `PREVIEW_ONLY=true` とWorkers Secretの `PREVIEW_ACCESS_TOKEN` を設定し、Assetsの `run_worker_first=true` を使う。鍵がなければ拒否する。`scripts/protected-preview.mjs` は127.0.0.1だけで待ち受け、サーバー側で鍵を付ける。起動時に `MENDAN_PREVIEW_URL` と `MENDAN_PREVIEW_TOKEN` を安全な取得元からプロセスへ渡す。会話の記録は行わない。

切り戻しは `ANSWER_PIPELINE=legacy` を指定した新しいプレビュー版を作り、ローカルproxyの接続先を切り替える。本人向け保護は維持する。プレビューの停止だけならproxyを終了する。公開サイトの稼働版は今回変更していない。

## 確認結果と制約

- 型チェック、ユニット347件、本番用Workerビルドが通過した。JEVの通信を模擬した本体APIで、Fact維持、生成・JEV上限、撤回、中止、エラー、復帰、音声への同一本文の受け渡し、既存のOrigin・利用制限を確認した。
- 既存画面から本体のAPIハンドラーへ接続し、架空データと外部応答の模擬で、文字・音声のJEV障害後の復帰、停止後の再質問、読み上げ後の次の質問を確認した。別途、音声画面のJEV障害のブラウザ回帰1件が通過した。
- 自動の実API確認は8問、各1回。通常6問、故意に因果を誤らせた候補の修復1問、合成音声の挨拶1問。生成8回・JEV9回・STT1回。旧D評価の使用数とは分けている。
- 通常6問は5問が回答、由来の1問は修復後も「不要な棄権」軸で却下された。回答が出た5問の画面表示は中央値5.36秒、範囲1.53〜9.93秒。拒否された1問は23.55秒。目標の中央値5秒以内は未達。初回・修復候補本文を保存しておらず、この1問が誤拒否かどうかは未確定。
- 因果を誤らせた1問では、JEVの根拠支持0.06・因果の非創作0.08で初回候補を却下し、修復後の部分回答だけを表示した。通常生成の正答率には数えない。
- JEVは9回の中央値0.49秒。検索は架空のメモリDB・固定ベクトルを使っており、本番検索の速度・精度を示す値ではない。本人資料への自動質問はしていない。
- 合成の「こんにちは」のSTTは3.37秒。既存音声画面で文字応答と入力復帰を確認した。手入力の初期設定が読み上げオフだったため、この実API確認ではTTSは未実行。実TTSの時間・実マイクの認識精度・本人資料での品質は本人試用で確認する。模擬TTSの確認結果と区別する。

JEVの速度だけで会話全体が速くなるとは限らず、生成と修復に待ち時間が残る。少数の架空例で、本人資料での誤回答や誤拒否がなくなることを保証しない。
